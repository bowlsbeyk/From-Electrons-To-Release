A running summary of the conventions fixed by merged chapters (full detail in each entry). A session can check this list without reading every entry, but should read the entries anyway.

| Convention | Fixed in | Rule |
| --- | --- | --- |
| Diagram palette, weights, vocabulary | Setup | See `diagrams/README.md` |
| Master diagram geometry | Setup | See `diagrams/README.md` §4 |
| Bit numbering in figures | Setup (confirmed in Ch. 4) | Bit 0 is least significant and drawn on the right |
| Memory in figures | Setup (confirmed in Ch. 19) | Addresses increase downward; stacks grow upward toward lower addresses |
| Hex and binary notation | Setup (confirmed in Ch. 19) | `0x2A`; `0b0010_1010` |
| Byte multiples | Setup | `KiB`, `MiB` for powers of two; `kB`, `MB` for powers of ten |
