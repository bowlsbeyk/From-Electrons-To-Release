# Glossary

Every term the book defines, alphabetically. Each entry gives the term, the one-line definition as the book gave it, where it was defined, and the other words the field uses that this book does not.

A term is defined once. Later chapters use the exact term and link back. Where the field uses more than one word for the same thing, the entry says which one the book uses and lists the others.

Format:

> **Term** — One-line definition. *(Chapter N, §Section.)* Also called: *alternatives, if any*.

---

**Cloze deletion** — A flashcard made by taking a true sentence and blanking out one word or phrase, so the context stays and one fact is tested. *(Chapter 0, §How to write a card.)* Also called: fill-in-the-blank card.

**Desirable difficulty** — A study condition that makes the moment harder (spacing, interleaving, testing instead of rereading, generating instead of reading) and builds durable memory because of it; only desirable if the learner can actually meet it. *(Chapter 0, §Why it has to be uncomfortable.)*

**Desired retention** — The target chance of recall at which a spaced-repetition scheduler brings a card back; FSRS defaults to 90%. *(Chapter 0, §The scheduler.)*

**Difficulty (FSRS)** — How hard a particular card is for you; governs how much its stability grows after each successful review. *(Chapter 0, §The scheduler.)*

**Fluency** — The feeling of ease when material goes by smoothly; a report on how easy the page was, not on whether you could produce it later. *(Chapter 0, §Two kinds of knowing.)*

**Foresight bias** — Overconfidence that comes from judging how well you know something while the answer is in front of you. *(Chapter 0, §Two kinds of knowing.)*

**FSRS** — The Free Spaced Repetition Scheduler: an open-source algorithm that models each card with retrievability, stability, and difficulty, and schedules the next review for the day retrievability will reach your desired retention. Built into Anki since version 23.10. *(Chapter 0, §The scheduler.)*

**Generation effect** — Material you produce yourself, even from a strong hint, is remembered better than the same material read off a page. *(Chapter 0, §Why it has to be uncomfortable.)*

**Illusion of competence** — Believing you know something because it feels familiar, when you could not produce it without the page. *(Chapter 0, §Two kinds of knowing.)* Also called: illusion of knowing, fluency illusion.

**Master diagram** — The book's single growing picture: thirteen bands from Physics at the bottom to Landing at the top, one box per chapter, each box lit as its chapter is read. *(Chapter 0, §Where we are.)*

**Meta-analysis** — A study that pools the results of many earlier studies to see what they say together. *(Chapter 0, §The fix is the test.)*

**Minimum information principle** — Each flashcard asks for exactly one fact; a card that asks for three is split into three. *(Chapter 0, §How to write a card.)*

**Preprint** — A research paper released before other researchers have reviewed it; treated as provisional. *(Chapter 0, §Labs with no AI open.)*

**Recall** — Producing something from memory when nothing is in front of you. *(Chapter 0, §Two kinds of knowing.)*

**Recognition** — Knowing something when you see it; what rereading produces. *(Chapter 0, §Two kinds of knowing.)*

**Retrievability** — In FSRS, the chance you could recall a card right now; it falls every day you do not review. *(Chapter 0, §The scheduler.)*

**Retrieval practice** — Studying by closing the material and producing it from memory, then checking; also called practice testing or the testing effect. *(Chapter 0, §The fix is the test.)*

**Retrieval strength** — How accessible a memory is right now; what fluency measures. *(Chapter 0, §Why it has to be uncomfortable.)*

**Savings method** — Ebbinghaus's way of measuring memory: the fraction of the original learning time saved when relearning the same material later. *(Chapter 0, §Forgetting is a tool.)*

**Self-explanation** — Explaining to yourself, as you read, why each step works; strongly supported when the prompt is "why," weakly when it is "how well do you understand." *(Chapter 0, §Why it has to be uncomfortable.)*

**SM-2** — The 1987 SuperMemo scheduling algorithm (one day, six days, then multiply by an easiness factor) that most flashcard software used before FSRS. *(Chapter 0, §The scheduler.)*

**Spacing effect** — The same amount of study spread over time produces better long-term retention than the same study massed together. *(Chapter 0, §Forgetting is a tool.)* Also called: distributed practice.

**Stability (FSRS)** — The number of days it takes a card's retrievability to fall from 100% to 90%. Not a half-life. *(Chapter 0, §The scheduler.)*

**Standard deviation** — A unit for how spread out a set of scores is; an effect of half of one is "clearly there, not enormous." *(Chapter 0, §The fix is the test.)*

**Storage strength** — How durably a memory is woven into what you already know; built by desirable difficulties, not measured by fluency. *(Chapter 0, §Why it has to be uncomfortable.)*

**The three tests** — Build it without AI; explain it back; survive the question. Every chapter holds the reader to all three. *(Chapter 0, §Where we are.)*
