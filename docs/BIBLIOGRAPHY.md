# Bibliography

Every source cited anywhere in the book, deduplicated, with the chapters that cite it. Grows in the same PR as the chapter that adds a source.

Format:

> Author or organization. *Title*. Edition or version, date. URL. (License, if open.) — Cited in: Ch. N, Ch. M.

Primary sources (specifications, standards, datasheets, ISA manuals, language references, official documentation) are listed first within each letter; secondary sources follow.
